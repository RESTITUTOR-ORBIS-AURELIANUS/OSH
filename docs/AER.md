# AER 算法介绍与具体实现

版本：`aer-v1.0.0`，对应 `VERSION` 中的 `1.0.0`。

AER（Adaptive Expert Replacement，自适应专家页面替换）同时模拟多种策略，根据近期缺页表现选择主要参考策略，再从真实驻留页中决定淘汰对象。这个版本固定了已经验证的 11 专家方案，不包含第二轮研究中未采用的候选。

## 1. 问题与约束

- 输入是页号序列，页框数为 C，初始内存为空。
- 命中时更新统计；缺页时装入当前请求页，内存满则先淘汰一页。
- 不预取、不读取未来。在线策略接口只有 `access(Page)`，返回 `true` 表示实际缺页。
- 每份 trace 和每个容量独立冷启动。默认容量 5、10、20、50、100，按五项缺页次数取算术平均；多份 trace 再等权平均。

AER 是本项目设计的组合策略。组成它的 LRU、ARC、MRU、衰减频率及自适应选择思想都有既有基础，不宣称具有对任意访问序列最优的证明。

| [baselines.hpp](../include/baselines.hpp) | FIFO、LRU、Second Chance、LFU、MRU、ARC，以及独立离线 OPT |
| [pager.cpp](../pager.cpp) | 输入校验、运行各算法、统计与输出 |
| [submission.cpp](../submission.cpp) | 自动合并后的独立 C++17 文件，与模块版行为相同 |

`AdaptivePolicy` 中的主要成员：

```cpp
experts_   // 各专家的影子状态
losses_    // 各专家的折扣缺页数
leader_    // 当前主要专家，下标初始为 0（LRU）
cache_     // 真实驻留集合：页号 -> 最近实际访问序号
```

**影子缓存仅保存页号和统计，不保存页面内容。** 每个专家最多模拟 C 个驻留页，另有历史元数据；真正能够命中的页面只有 `cache_` 中的 C 个页。实际缺页不使用专家的命中结果代替。

## 3. 11 个专家

| 专家 | 数量 | 参数与作用 |
|---|---:|---|
| LRU | 1 | 淘汰最久未访问的页 |
| ARC | 1 | 根据幽灵命中调整近期性与重复访问的平衡 |
| MRU | 1 | 淘汰最近访问页，为部分循环模式提供互补 |
| 衰减频率 | 4 | 半衰期为 2C、8C、32C、128C |
| 频率＋周期预测 | 3 | 指数衰减时间尺度 τ 为 C、4C、16C |
| 历史片段预测 | 1 | 至多比较 64 个旧位置、32 个后缀符号，最小匹配长度为 1 |

### 衰减频率

每次访问贡献 1，旧贡献随时间减小。在该页当前统计条目保留期间：

$$
S_p(t)=\sum_{u\le t:\,x_u=p}2^{-(t-u)/h}.
$$

淘汰 S 最小的页，同分按 LRU。不同半衰期 h 分别适应较快变化和较稳定的热点。实现用对数分数比较，避免频率衰减后的数值问题；极小贡献会作截断。非驻留页的历史条目被裁剪后，再次出现重新计数。

### 频率＋周期预测

每页记录最近访问序号 `last`、衰减频率 `frequency`、上一次复用间隔 `gap` 和连续稳定计数 `stable`。

新访问到来，令 g 为距上次访问的请求数：

$$
f\leftarrow f e^{-g/\tau}+1.
$$

若 g 与上一次间隔的差不超过 `max(1, 0.1 × 上一次间隔)`，增加稳定计数，否则重新计数。至少两个相似间隔才启用周期预测。

淘汰时，设页当前年龄为 a：

$$
d_f=\frac{\tau}{\max(f e^{-a/\tau},10^{-12})},\qquad
 d_p=\max(1,g-a).
$$

没有稳定周期时采用频率延迟估计 d_f；有两个稳定间隔时用 `0.75 d_p + 0.25 d_f`，三个及以上用 d_p。如果年龄已超过 `1.25g`，回退到 d_f。淘汰估计等待时间最长的页，同分按 LRU。

例如过去访问间隔持续约为 20，距上次访问已经过去 18 次请求，则预测约 2 次请求后会复用，应倾向保留。该预测可能出错，不会因此提前载入页面。

### 历史片段预测

在有界环形历史中寻找与当前后缀相同的旧片段，把旧片段之后**已经发生的访问**作为预测。较长匹配还允许重复历史周期进行预测。预测中较晚出现的驻留页优先淘汰；没有有效预测时回退到衰减频率。

它只根据页号相等关系匹配，不依据地址大小、文件名或测试集身份选择规则。

## 4. 评分与切换

每次请求到来，先让所有专家处理当前页，随后更新：

$$
L_j(t)=\rho L_j(t-1)+m_j(t),\quad
\rho=2^{-1/H},\quad H=\max(64,32C).
$$

m_j 为该专家本次模拟缺页指示，缺页为 1、命中为 0。L_j 越小越好；经过 H 次请求，某次旧缺页对评分的影响减半，因此旧阶段不会永久主导决策。

只有最佳专家相对当前主要专家的优势**严格超过** `max(1, 0.5C)` 时才切换。这个门槛避免不同驻留集之间频繁震荡。它是开发实验选定的工程参数，没有理论最优性保证。

## 5. 实际换页

设真实集合为 R，主要专家处理当前页 x 后的影子集合为 S。

1. 若 x∈R：只更新真实访问时间，返回命中。
2. 若 x∉R 且内存未满：直接装入 x，返回缺页。
3. 若 x∉R 且内存已满：候选为 `R \ S`。
4. 其他专家对其影子驻留页投保护票，权重为：

$$
w_j=\exp\left(-\frac{L_j-\min_i L_i}{4}\right),\qquad
V(p)=\sum_{j:p\in S_j}w_j.
$$

5. 在候选中淘汰 V 最小的页；同票选真实最久未访问者。随后只装入 x。

权重小于 `1e-9` 的专家不参与投票。候选一定非空：内存已满时 R 有 C 个页且不含 x，而 S 最多 C 个页并含 x，因此 S 不可能包含 R 的所有页。

```text
access(x):
    所有专家处理 x，更新折扣缺页评分
    如果最佳专家的优势超过切换阈值，更新主要专家
    如果 x 在真实集合中，更新时间并返回命中
    如果真实集合已满：
        候选 = 真实集合 - 主要专家的影子集合
        淘汰候选中保护票最少的页，同票按 LRU
    仅把 x 装入真实集合
    返回缺页
```

例如真实内存为 `{A,B,C}`，当前请求 D，主要专家的影子集合为 `{B,D,E}`（E 曾在过去访问过）。候选是 A、C。若投票更支持 A，实际结果为 `{A,B,D}`。**不会因为专家保留 E 就把 E 装入。**

切换专家同样不会复制整个影子集合，也不会把“所有专家中最小的缺页数”作为实际成绩。评分用于决策，最终成绩来自真实集合逐次计数。

## 6. 开销和效果

AER 需要维护 11 套模拟状态，CPU 和元数据成本高于 LRU。即使实际命中，某个专家也可能模拟缺页并进行扫描。

每个衰减专家的历史最多 `max(256,32C)` 项；周期专家最多 `max(512,64C)` 项；历史片段专家保留 `max(1024,64C)` 个请求及有界统计。元数据可以超过 C，但可命中的真实页始终不超过 C。固定专家数和候选搜索上限后，时间开销随 C 及有界历史长度增长，哈希操作按期望 O(1) 计。

四份给定数据 × 五种容量，共 20 个组合：

| 算法 | 平均缺页次数 |
|---|---:|
| FIFO | 25378.35 |
| LRU | 24438.00 |
| Second Chance | 24470.90 |
| **AER** | **16834.10** |
| OPT（离线下界） | 16309.80 |

AER 比 LRU 少 31.12%；这只是这些数据上的测量，不保证任意未知序列都更好。OPT 单独标识为离线算法，只有它可以读取未来。

`make test` 包含基准与独立动态规划的 OPT 对照、在线驻留/缺页/禁止预取检查、前缀与页号重命名检查、CLI 测试，以及四份数据上 200 个算法/容量组合的固定结果回归。版本源码与数据通过 [manifest](../release/manifest.json) 的 SHA-256 校验。
